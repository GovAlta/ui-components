# Spacer

Negative area between the components and the interface.

**Status:** stable | **Category:** Utilities | **Docs:** https://design.alberta.ca/components/spacer

---

## React

### Props

| Prop | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| `hSpacing` | GoabSpacerHorizontalSpacing | `none` | No | Horizontal spacing. |
| `testId` | string | (none) | No | Sets a data-testid attribute for automated testing. |
| `vSpacing` | GoabSpacerVerticalSpacing | `none` | No | Vertical spacing. |
