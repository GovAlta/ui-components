# Work Side Menu Group

Collapsible group of items within the work side menu.

**Status:** stable | **Category:** Structure And Navigation | **Docs:** https://design.alberta.ca/components/work-side-menu-group

---

## React

### Props

| Prop | Type | Default | Required | Description |
|------|------|---------|----------|-------------|
| `heading` | string | — | Yes | The text displayed in the group heading. |
| `icon` | GoabIconType | — | No | Icon displayed before the group label. When omitted, no icon is rendered and no space is reserved. |
| `open` | boolean | — | No | Whether the group is open. |
| `testId` | string | — | No | Sets a data-testid attribute for automated testing. |
