Feat #1351: Dropdown item slot View on GitHub The ability to have a slot for Dropdown Items that can be filled with anything (HTML). This needs to be supported for the filterable property (Combobox), where any/all text included in the slot is filterable. Multiple line support, icon and badge to indicate status. The label property is shown in the input once an item is selected.
