Bug 3447: Browser styling for p tags View on GitHub When GoabText renders a paragraph, setting mt or mb to none should explicitly apply a zero margin and override the browser's default paragraph styling. 1. Margins set to s The paragraph should have small top and bottom margins between the dividers. Paragraph with mt="s" and mb="s" 2. Margins not set The paragraph should use the Text component defaults: s on top and l on the bottom. Paragraph without mt or mb 3. Margins set to none The paragraph should touch both dividers because none resolves to zero and overrides the browser's native 1em paragraph margins. Paragraph with mt="none" and mb="none"
