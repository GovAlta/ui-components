Bug #4201: Disabled radio groups with Angular forms 1. Template-driven form using [disabled] property The component input supplies the disabled state while ngModel supplies the value. 2. Reactive form disabled via FormControl The FormControl is created with disabled: true. The component has no disabled input. FormControl disabled: {{ formControlDisabled.disabled }} 3. Reactive form disabled using [disabled] property The FormControl remains enabled while the disabled state is supplied directly to the component. This is the option that didn't work prior to this bug. This is technically the incorrect way of doing it and shouldn't be used. It's been fixed though because some people will inevitably do it this way. It's incorrect because while it disables the component in the UI, it doesn't disable it to Angular, so Angular will still present the value in any FormGroup values. FormControl disabled: {{ componentDisabled.disabled }} (expected: false)
