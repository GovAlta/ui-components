<goa-text size="heading-xl" mt="none" mb="m">Developer setup</goa-text>
<goa-text size="body-l" mt="none" mb="2xl">Set up the Government of Alberta Design System in Angular, React, or directly with Web Components.</goa-text>

<h2 id="angular">Angular UI components</h2>
<goa-callout version="2" type="information" emphasis="low" mb="m">
  <goa-text size="body-m" mt="2xs" mb="none">Supported versions: 18, 19, 20, 21</goa-text>
</goa-callout>
<goa-text size="body-m" mt="none" mb="m">
  This library contains standalone Angular components that wrap the Government of Alberta
  Web Components.
</goa-text>

<h3 id="angular-step-1">1. Add dependencies</h3>
<pre><code>{`npm i @abgov/web-components
npm i @abgov/angular-components
npm i @abgov/ui-components-common`}</code></pre>

<h3 id="angular-step-2">2. Register the web components</h3>
<goa-text size="body-m" mt="none" mb="m">
  Import the underlying web components once in <code>src/main.ts</code>, before
  bootstrapping the application:
</goa-text>
<pre><code>import "@abgov/web-components";</code></pre>
<goa-text size="body-m" mt="none" mb="m">
  Keep your existing <code>bootstrapApplication</code> call after this import.
</goa-text>

<h3 id="angular-step-3">3. Import wrapper components</h3>
<goa-text size="body-m" mt="none" mb="m">
  Import each standalone wrapper directly into the component that uses it:
</goa-text>
<pre><code>{`// src/app/app.ts
import { Component } from "@angular/core";
import { GoabButton } from "@abgov/angular-components";

@Component({
  selector: "app-root",
  standalone: true,
  imports: [GoabButton],
  template: '<goab-button type="primary">Continue</goab-button>',
})
export class App {}`}</code></pre>
<goa-text size="body-m" mt="none" mb="m">
  <code>standalone: true</code> is shown explicitly for compatibility with Angular 18; it
  is the default in newer Angular versions.
</goa-text>
<goa-text size="body-m" mt="none" mb="m">
  For an existing NgModule-based application, add each standalone wrapper component to
  that module&apos;s <code>imports</code> array. <code>AngularComponentsModule</code> is only
  needed by applications that still use the legacy <code>goaValue</code>,
  <code>goaValueList</code>, or <code>goaChecked</code> form directives.
</goa-text>

<h3 id="angular-step-4">4. Add styles</h3>
<goa-text size="body-m" mt="none" mb="m">
  Import the component styles in <code>src/styles.css</code>. This stylesheet includes the
  design tokens and dark theme overrides:
</goa-text>
<pre><code>@import "@abgov/web-components/index.css";</code></pre>

<h3 id="angular-step-5">5. Add icons</h3>
<goa-text size="body-m" mt="none" mb="m">
  Add Ionicons to the <code>head</code> element of <code>src/index.html</code>:
</goa-text>
<pre><code>{`<script type="module" src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.esm.js"></script>
<script nomodule src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.js"></script>`}</code></pre>

<goa-divider mt="xl" mb="xl"></goa-divider>

<h2 id="react">React UI components</h2>
<goa-callout version="2" type="information" emphasis="low" mb="m">
  <goa-text size="body-m" mt="2xs" mb="none">Supported versions: 17, 18, 19</goa-text>
</goa-callout>
<goa-text size="body-m" mt="none" mb="m">

<pre><code>npm i @abgov/react-components
npm i @abgov/web-components

<h3 id="react-step-2">2. Link ionicons in app/index.html</h3>

<pre><code>{`<script type="module" src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.esm.js"></script>
<script nomodule src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.js"></script>`}</code></pre>

<h3 id="react-step-3">3. Import the web components in src/main.tsx</h3>
<pre><code>import "@abgov/web-components";</code></pre>

<h3 id="react-step-4">4. Import the styles in src/index.css</h3>
<goa-text size="body-m" mt="none" mb="m">
  This stylesheet includes the design tokens and dark theme overrides:
</goa-text>
<pre><code>@import "@abgov/web-components/index.css";</code></pre>

<goa-divider mt="xl" mb="xl"></goa-divider>

<h2 id="web-components">Web components</h2>
<goa-text size="body-m" mt="none" mb="m">
  This library contains web components from the Government of Alberta.
</goa-text>

<h3 id="web-step-1">1. Add dependencies</h3>
<pre><code>npm i @abgov/web-components</code></pre>

<h3 id="web-step-2">2. Link ionicons in index.html</h3>
<goa-text size="body-m" mt="none" mb="m">
  Add the following in the <code>head</code> element:
</goa-text>
<pre><code>{`<script type="module" src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.esm.js"></script>
<script nomodule src="https://cdn.jsdelivr.net/npm/ionicons@latest/dist/ionicons/ionicons.js"></script>`}</code></pre>

<h3 id="web-step-3">3. Import the web components into src/main.js</h3>
<pre><code>import "@abgov/web-components";</code></pre>

<h3 id="web-step-4">4. Add the styles link in your main CSS file</h3>
<goa-text size="body-m" mt="none" mb="m">
  Add the following in <code>src/assets/main.css</code> or wherever your main CSS file is
  located. This stylesheet includes the design tokens and dark theme overrides:
</goa-text>
<pre><code>@import "@abgov/web-components/index.css";</code></pre>

<goa-divider mt="xl" mb="xl"></goa-divider>

<h2 id="sass-variables">Use Sass variables</h2>
<goa-text size="body-m" mt="none" mb="m">
  The Web Components stylesheet includes the design tokens and dark theme overrides. You
  only need to install the design tokens package if you want to use its Sass variables
  directly in your own styles.
</goa-text>

<h3 id="sass-step-1">1. Add the design tokens package</h3>
<pre><code>npm i @abgov/design-tokens</code></pre>

<h3 id="sass-step-2">2. Import the Sass variables</h3>
<goa-text size="body-m" mt="none" mb="m">
  Import the variables into the Sass file where you need them:
</goa-text>
<pre><code>@use "@abgov/design-tokens/dist/tokens" as *;</code></pre>
<pre><code>{`.my-card {
  padding: $goa-space-m * 2;
  border-radius: $goa-border-radius-m;
}`}</code></pre>

<goa-callout version="2" type="important" emphasis="low" mb="xl">
  <span style="color: var(--goa-color-text-default)">
    Sass variables are set when your styles compile and cannot change with the active
    theme. Use CSS custom properties such as <code>{`var(--goa-*)`}</code> for colours,
    surfaces, and other values that need to switch between light and dark themes.
  </span>
</goa-callout>
