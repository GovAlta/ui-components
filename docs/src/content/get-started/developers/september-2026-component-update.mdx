<goa-text size="heading-xl" mt="none" mb="m">September 2026 component library update</goa-text>
<goa-text size="body-l" mt="none" mb="m">The September 2026 update introduces Web components 3, Angular components 6, and React components 8. These major releases include breaking API changes that may require updates to your application.</goa-text>
<p>If your team has already upgraded to Web components 2.x and the updated design system, you should not need to make any other changes beyond those listed on this page.</p>

<goa-callout type="information" emphasis="low" heading="Package versions" mt="l" mb="xl">
  <ul>
    <li>Web components: 2.x to 3.x</li>
    <li>Angular components: 5.x to 6.x</li>
    <li>React components: 7.x to 8.x</li>
  </ul>
</goa-callout>
