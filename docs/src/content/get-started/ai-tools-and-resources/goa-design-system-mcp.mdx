<goa-text as="h2" id="setup" size="heading-m" mt="2xl">Setup</goa-text>

<p>Find your AI tool below to connect it. The MCP runs on your computer through <code>npx</code>, so you need Node 20 or newer.</p>

<goa-callout type="important" emphasis="low" mt="m" mb="m">
  <goa-text size="body-m" mt="none" mb="none">To verify your setup, restart your AI tool and ask "Look up the GoA Button component." You should get a response covering Button's props, variants, and usage.</goa-text>
</goa-callout>

<goa-text as="h3" size="heading-xs" mt="xl">Claude Code (CLI)</goa-text>

<p><goa-link mt="s" trailingicon="open"><a href="https://code.claude.com/docs/en/mcp" target="_blank" rel="noopener noreferrer">View Claude Code's MCP documentation</a></goa-link></p>

<p>The fastest path is the <code>claude mcp add</code> command:</p>

<CodeSnippet language="bash" showCopy client:visible code={`claude mcp add goa-design-system -- npx -y @abgov/design-system-mcp`} />

<goa-text as="h3" size="heading-xs" mt="xl">Claude Desktop</goa-text>

<p><goa-link mt="s" trailingicon="open"><a href="https://modelcontextprotocol.io/docs/develop/connect-local-servers" target="_blank" rel="noopener noreferrer">View Claude Desktop's MCP setup guide</a></goa-link></p>

<p>Edit the config file at:</p>

<ul>
  <li>Mac: <code>~/Library/Application Support/Claude/claude_desktop_config.json</code></li>
  <li>Windows: <code>%APPDATA%\Claude\claude_desktop_config.json</code></li>
</ul>

<CodeSnippet language="json" showCopy client:visible code={mcpServersConfig} />

<goa-text as="h2" id="versions" size="heading-m" mt="2xl">Versions</goa-text>

<p>Each version answers for the Design System release it shipped with. The setup above uses the newest version. To match the components you're building with, use the same version as your <code>@abgov/web-components</code> package, for example <code>@abgov/design-system-mcp@x.y.z</code>.</p>

<p>Every published version stays available. <goa-link trailingicon="open"><a href="https://www.npmjs.com/package/@abgov/design-system-mcp" target="_blank" rel="noopener noreferrer">View versions on npm</a></goa-link></p>
